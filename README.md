# 🚗 RentACar Clone

A functional web-based car rental platform inspired by modern car rental websites.

The application allows users to browse rental cars, search for cars, filter available vehicles, view car details, and complete a rental booking.

---

## 📌 Project Overview

RentACar is a full-stack web application developed as a functional clone project.

Users can:

- Search for rental cars
- Select pickup and return dates
- Select a pickup location
- Browse available cars
- Filter cars by type
- Filter cars by fuel type
- Filter cars by brand
- Filter cars by price
- Sort cars by price or rating
- View detailed information about a car
- Book a selected car
- View booking confirmation
- Contact the rental service
- Read information about RentACar
- Sign in through the demo sign-in page
